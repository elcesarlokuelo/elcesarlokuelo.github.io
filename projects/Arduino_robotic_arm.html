Arduino Robotic Arm

Arduino · FreeCAD · Robotics

This project involves building a small-sized robotic arm. Motion control is handled by an Arduino MEGA 2560. The robot's parts are manufactured using a 3D printer and designed in FreeCAD. Additionally, Python is used to build a graphical interface on a computer to send commands to the arm. If needed, inverse kinematics calculations can also be performed on the computer, in case the Arduino doesn't have enough processing power for them.

All project content is available in the repository: https://github.com/elcesarlokuelo/Arduino_Robotic_Arm

This project is currently in progress, and the repository will be updated as new developments occur. The goal is to build a fully functional robotic arm using several SG90 servo motors and an MG995 servo motor for the base rotation. The arm will be capable of performing tasks such as picking up objects, moving them, and placing them at different locations.

Additionally, the project will include a graphical interface that allows users to control the arm's movements and perform tasks from a computer.

Hardware

The main hardware components used are:

  • Arduino MEGA 2560 microcontroller: 8-bit microcontroller based on the ATmega2560. It has 54 digital input/output pins, 16 analog inputs, and a USB connection for programming and communication with a computer.
  • SG90 servomotors: small, lightweight servomotors commonly used in robotics projects. They are controlled by pulse-width modulation (PWM) signals from the Arduino and are used for the arm's joints, providing precise control of its movements. Their main limitation is that only position can be controlled, not speed: they cannot rotate continuously, and PID-type control cannot be applied to them.
  • MG995 servomotor: similar to the SG90 but larger and more powerful, it is used for the base rotation of the arm. It has metal gears and can rotate up to 180 degrees, although it is likewise not capable of continuous rotation.

Software

The microcontroller was programmed in Arduino IDE using C++.

Mechanical Design

Parts were modelled in FreeCAD and printed in PLA using an Anycubic Kobra 2 printer. These parts are subject to change as the design is still in progress, and some of them may need to be redesigned to improve performance or fix issues.
